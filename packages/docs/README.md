# docs

The nadle.dev site, built with [VitePress](https://vitepress.dev/).

```bash
pnpm exec nadle packages:docs:dev        # serve with hot reload
pnpm exec nadle packages:docs:buildSite  # build into .vitepress/dist, then check the output
```

Pages live in `docs/` and `blog/`; the sidebar is `.vitepress/sidebar.json`. These are generated by tasks
that `bundleSite` depends on, and are gitignored apart from the CLI reference:

- `docs/cli-reference.md`: from the CLI option definitions (`scripts/build-cli-reference.ts`)
- `public/spec/`: the specification in `spec/` as HTML (`scripts/build-spec.ts`)
- `docs/api/` and `.vitepress/api-sidebar.json`: API reference from typedoc (`scripts/adjust-api-markdown.ts`)
- `public/rss.xml`, `public/llms.txt`, `public/llms-full.txt`: feed and agent-facing indexes

VitePress runs on vite 5 here (see the `vitepress>vite` override in `pnpm-workspace.yaml`): under the repo-wide
vite override its build exits 0 but omits the per-page chunks. `scripts/check-chunks.ts` fails the build if a page
references a JS file that was not emitted.

Netlify runs `nadle packages:docs:buildSite` and publishes `.vitepress/dist` (see `netlify.toml`, which also
redirects URLs of the previous site that no longer exist).
